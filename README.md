# Marketing engineer playbook

The method behind a fixed-scope marketing engineering engagement, written in the open: how the offer gets
written, which distribution artifacts survive the week, how scope and prices are published, and how a test is
declared dead before it wastes the budget.

Written by [Axel Freeman](https://axelfreeman.com/). The method is free to read and copy. The
done-for-you version — offer page, query-intent source pages, schema and `llms.txt`, a free tool, deliverability
setup, tests with a written kill rule, and the tracked event in your own analytics property — is built in fixed
packages: **Sprint $900** one-time, **Engine $1,900/month**, **Full build $2,900** one-time.
[What a marketing engineer does and what the invoice pays for ->](https://axelfreeman.com/marketing-engineer.html)
