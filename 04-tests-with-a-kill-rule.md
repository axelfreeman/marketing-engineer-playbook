# 04 — Tests with a kill rule

A test without a pre-declared floor is a coin flip with a nicer chart.

1. **State the volume before you start.** For a two-variant reply-rate test with a 3% baseline and a target of
   +20% relative, that is roughly 13,900 sends per variant at 80% power and 95% confidence. If you cannot send
   that much, do not read the result — change the channel or change the question.
2. **Write the kill rule in the same document**: expected conversions, the floor below which the variant dies,
   and the date.
3. **Record the baseline before the test.** The most common cheat in reported results is a baseline defined
   after the fact.
4. **One event matters.** Clicks into a conversation. Everything else on the dashboard supports it.
